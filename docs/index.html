      Features

      What you can change

      Iconify applies its tweaks through Android overlays and the Xposed framework. Some features require LSPosed (or another Xposed framework) — the rest work with root alone. Exact availability varies by Android version: v7.3.0 (Android 12 – 16) and v8.0.0+ (Android 16 QPR1+) each offer a slightly different set.

      System icon packs

      Swap system icons with packs like Aurora, Gradicon, Lorn, Plumpy and more — including WiFi, cellular, media player and Settings icons, plus custom icon shapes.

      Color engine

      Apply solid or gradient accent colors, or drive the whole Material You palette from the monet engine with custom colors and saturation.

      Quick Settings panel

      Change QS tile shapes, rows and columns, tile size, icon and label options, panel margins and QS themes — plus panel transparency and blur.

      Lockscreen

      Add custom lockscreen clocks, weather, widgets, media album art and a music visualizer — or an iOS-like depth wallpaper effect.

      Statusbar & battery styles

      Modify the statusbar, recolor the battery icon, pick custom battery styles, and add a statusbar logo, clock chip or dual statusbar.

      Header image & clock

      Put a custom image or clock on the Quick Settings panel header.

      Notifications & media

      Customize the notification style, media player style and toast frame to match the rest of your setup.

      Volume panel

      Restyle the volume panel with custom designs.

      UI roundness & bars

      Change the corner radius of the whole interface, restyle the brightness bar and progress bars, and tweak navigation bar options.

      Requirements

      What you need

      Android 12+ Pixel / AOSP ROM Android 12 – 16 (non-QPR): use v7.3.0 · Android 16 QPR1 and later: use v8.0.0+. Other OEM skins (MIUI, OneUI, ColorOS…) are not supported.
      Root access Magisk, KernelSU or APatch. KernelSU v3.0+ users also need Mountify (or another metamodule), otherwise some features will be missing.
      Xposed framework (optional) LSPosed, Vector or another Xposed framework unlocks extras like header clocks, lockscreen clocks, header image and battery styles.
      Custom recovery (recommended) A decryption-supported custom recovery, just in case you need to revert changes.

      FAQ

      Common questions

      How does Iconify work?
      Iconify uses Android overlays and the Xposed framework, so modifications apply to the device's UI without directly modifying the underlying system files.
      Do I need root access?
      Yes, root access is required. KernelSU and APatch are supported, but Magisk is highly recommended for the best compatibility.
      Why is LSPosed optional?
      Most features work without it. Installing LSPosed adds extras such as header clocks, lockscreen clocks, header image and battery styles.
      Which devices are supported?
      Iconify exclusively supports stock Pixel or custom AOSP ROMs. It does not support other OEM skins such as MIUI, OneUI, ColorOS, NothingOS or MotoUI. Heavily modified ROMs are discouraged.
      Which version do I need for my Android version?
      Android 12 to Android 16 (non-QPR): use v7.3.0. Android 16 QPR1 and later: use v8.0.0 and later. Versions below Android 12 are not supported and there are no plans to add support.
      What's the difference between FOSS and Standard builds?
      The FOSS build does not include ML Kit, which is used to automatically extract subjects from depth wallpapers using AI. Everything else is the same.
      I got a bootloop. How do I fix it?
      Boot into Safe Mode, or remove the Iconify folder from /data/adb/modules/ using a custom recovery.
